# equity-oauth

The public home page, privacy policy and terms of service for **Equity local Import**, a personal
command-line tool. Google requires these links before an External OAuth app can be published.

Served by GitHub Pages from the `gh-pages` branch:

- Home: https://stopitg.github.io/equity-oauth/
- Privacy policy: https://stopitg.github.io/equity-oauth/privacy.html
- Terms of service: https://stopitg.github.io/equity-oauth/terms.html
