Privacy policy

Equity local Import · Last updated 2 November 2026

Equity local Import is a personal command-line tool that its owner runs on their own computer. This policy explains what Google user data it accesses, how it uses and stores that data, and how to remove its access.

Data it accesses

  • It requests a single Google permission, drive.file (https://www.googleapis.com/auth/drive.file). That gives it access only to the spreadsheets you choose in Google's file picker when you sign in.
  • It reads and writes the cells, formatting and named ranges of those chosen spreadsheets through the Google Sheets API.
  • It doesn't access any other file, your email, contacts, calendar or profile.

How it uses the data

It uses the chosen spreadsheets only to do what you ask: it reads them to decide what to update, and it writes public financial data from the SEC's EDGAR system into them. It doesn't use Google user data for advertising, it doesn't sell it, and it doesn't use it to train AI or machine-learning models.

Where the data is stored

  • The program runs only on your own computer. There is no server, and it doesn't send Google user data to the developer or to any third party. Its only network destinations are Google's own sign-in and Sheets services and the SEC's public EDGAR site, which receives no Google data.
  • After sign-in, it saves one item on your computer: a Google refresh token, in a file readable only by your user account. Access tokens are kept in memory only while the program runs.
  • Spreadsheet contents stay in your Google Drive. The program keeps no copy after it finishes.

Sharing

Google user data is not shared with, sold to or transferred to anyone. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

  • Revoke the program's access at any time at myaccount.google.com/permissions.
  • The program's own revoke command revokes the token with Google and then deletes the saved token file. Deleting that file yourself also removes the stored token from your computer.

Changes and contact

Changes to this policy will be posted on this page with a new date. Questions can be raised as an issue on this site's GitHub repository.
